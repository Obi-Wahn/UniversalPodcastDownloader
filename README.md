# PodcastDownloader
Ein plattformübergreifendes PowerShell-Skript (Windows &amp; Linux) zum automatisierten Archivieren von Podcasts via RSS. Es extrahiert MP3-Links, umgeht CDN-Sperren, bereinigt Dateinamen und nummeriert Folgen automatisch zur alphabetischen Sortierung. Inkrementelle Downloads sparen Speicher und Bandbreite. Perfekt für das lokale Podcast-Archiv!
